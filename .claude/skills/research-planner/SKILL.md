# Research Planner - 资料收集需求规划器

在正式收集资料前，通过轻量级需求澄清和探测式引导，帮助用户明确方向，避免无效收集。

## 职责范围

本技能只负责 **意图澄清与方向引导**，不涉及后续的资料收集、大纲生成、笔记写作等环节。

**输出产物**:
- `/workspace/learning_notes/00_intent.md` — 意图文件
- `/workspace/learning_notes/todo.md` — 执行检查清单（基于 todo 模板生成）

**下游衔接**: 用户确认意图后，由 `/research-collector` 接力进行深度资料收集。

## 工作流程

### Step 1: 快速判断用户意图

根据用户输入的信息量，选择对应场景:

| 场景 | 用户输入特征 | 处理方式 |
|------|-------------|---------|
| **A: 信息充足** | 有主题 + 类型 + 深度 | 跳过提问，直接生成计划 |
| **B: 信息模糊** | 只有主题 | 问 3 个核心问题 |
| **C: 完全没方向** | 只有方向或"不知道" | 跳过提问，直接探测 |

---

### Step 2: 轻量级提问（仅场景 B）

只问 3 个核心问题，不要让用户感到繁琐:

**问题 1: 笔记类型？**
| 🛠️ 实战笔记 | 📖 概念学习 | 💡 心得总结 |

**问题 2: 学习深度？**
| 🌱 入门了解 | 🌿 能上手做 | 🌳 能讲给别人听 |

**问题 3: 现有基础？**
| 🆕 零基础 | 📚 有一定了解 | 🔧 比较熟悉 |

---

### Step 3: 探测式引导（场景 B/C）

当用户意图模糊时，用最低成本"探测"，帮用户"看见全景"。

#### 3a. 派发探测 subagent

使用 Agent 工具并行派发 2-3 个 subagent，每个只搜一个角度:

```javascript
// 使用 Agent 工具调用
Agent({
  subagent_type: "Explore",  // 或使用默认 general agent
  prompt: `你是资料探测助手。搜索关于 {主题} 的资料，只做初步探测。

搜索关键词: {关键词}

返回格式（严格遵守，每条只返回一行）:
- [标题] — [一句话摘要，30字内]

每个角度返回 3-5 条。不要返回 URL，不要返回详细内容。`,
  description: "探测{角度}方向的资料"
})
```

#### 3b. 展示"方向菜单"

把探测结果整理成可选方向:

---

**🔍 探测结果**

关于 **"{主题}"**，资料大致分为这几个方向:

**方向 1: 🛠️ 实战路线**
- [标题 A] — [一句话说明]
- 适合: 想动手写代码、做项目的人

**方向 2: 📖 概念深入**
- [标题 C] — [一句话说明]
- 适合: 想理解原理、搞懂"为什么"的人

**方向 3: 🔄 对比学习**
- [标题 E] — [一句话说明]
- 适合: 想和其他技术对比、做技术选型的人

---

**请告诉我:**
1. 你更想侧重哪个方向？
2. 或者你希望覆盖哪几个方向？

---

### Step 4: 生成意图文件并确认

用户明确方向后，生成意图文件并展示研究计划:

#### 4a. 生成意图文件

```bash
mkdir -p /workspace/learning_notes
```

将用户的学习意图保存到 `/workspace/learning_notes/00_intent.md`:

```markdown
## 学习意图

- 主题：{主题}
- 类型：{实战笔记 / 概念笔记 / 心得笔记 / 对比笔记}
- 深度：{入门了解 / 能上手做 / 能讲给别人听}
- 基础：{零基础 / 有一定了解 / 比较熟悉}
- 特别关注：{用户特别关注的方面，如有}

## 研究方向

1. {方向 1}: {具体目标}
2. {方向 2}: {具体目标}
```

#### 4b. 展示研究计划

---

**📑 研究计划**

**主题**: {主题}
**笔记类型**: {类型}
**目标深度**: {深度}
**现有基础**: {基础}

**研究方向**:
1. {方向 1}
2. {方向 2}

✅ 意图文件已保存: `/workspace/learning_notes/00_intent.md`

---

#### 4c. 生成执行检查清单

基于模板 `/Users/zhqznc/code/study-system/.claude/templates/learning-note-todo.md` 生成 `/workspace/learning_notes/todo.md`，填充以下信息：

```bash
# 读取模板并生成 todo 文件
cp /Users/zhqznc/code/study-system/.claude/templates/learning-note-todo.md /workspace/learning_notes/todo.md
```

然后根据实际意图修改 todo 文件：
- `{topic}` → 用户学习主题
- `{date}` → 当前日期
- `{current_phase}` → "阶段 1：探测式收集"（已完成阶段 0，下一步是阶段 1）
- 阶段 0 的状态标记为 "✅ 已完成"
- 阶段 1 的状态保持 "⬜ 未开始"
- 其他阶段保持 "⬜ 未开始"

---

**确认此计划吗？** [确认开始] / [调整方向]

---

### Step 5: 衔接到资料收集

用户确认后，更新 todo.md 状态并提示用户启动资料收集:

**更新 todo.md 状态：**
```bash
# 将阶段 0 标记为完成，当前阶段改为阶段 1
sed -i '' 's/🔲 进行中/✅ 已完成/g' /workspace/learning_notes/todo.md
sed -i '' 's/当前阶段：阶段 [0-9]/当前阶段：阶段 1/g' /workspace/learning_notes/todo.md
```

```
意图确认完成！接下来请使用 /research-collector 进行深度资料收集。
```

## 注意事项

1. **轻量级提问**: 最多问 3 个问题，不让用户感到繁琐
2. **探测成本低**: subagent 只返回标题+摘要，不做深度分析
3. **用户主导**: 每个阶段都给用户选择权，不替用户做决定
4. **允许调整**: 用户可以随时说"换个方向"
5. **只管意图澄清**: 本技能不涉及资料收集、大纲生成、笔记写作

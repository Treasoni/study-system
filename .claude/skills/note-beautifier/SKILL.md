# Note Beautifier - Obsidian 笔记智能美化专家

协调调用 Obsidian 基础技能，为笔记应用专业美化方案。

## 核心架构

```
note-beautifier (协调层)
    │
    ├── 分析笔记类型和内容特征
    │
    ├── 生成美化方案
    │
    └── 调用基础技能执行
         │
         ├── /obsidian:markdown  (Markdown 语法处理)
         ├── /obsidian:cli       (Vault 操作)
         └── /obsidian:bases     (数据库操作)
```

## 触发条件

当用户提出以下类型的请求时，调用此技能:

- "帮我美化一下这个笔记"
- "优化 Obsidian 笔记格式"
- "让笔记更好看"
- "笔记排版优化"
- "应用 Obsidian 美化"
- 任何涉及 Obsidian 笔记美化的请求

## 核心功能

### 功能 1: 笔记类型智能识别

自动分析笔记内容，识别类型并推荐相应的美化方案。

**识别维度**:
```yaml
内容类型:
  - 学习笔记 (教程、课程、学习总结)
  - 读书笔记 (书籍、文章、论文)
  - 项目笔记 (技术文档、方案设计)
  - 会议记录 (会议纪要、讨论记录)
  - 知识卡片 (概念、定义、公式)
  - 工作日志 (日报、周报、复盘)

结构特征:
  - 层级结构 (有无明确的章节划分)
  - 代码比例 (代码块占比)
  - 列表密度 (有序/无序列表数量)
  - 表格使用 (数据表格数量)
  - 引用内容 (引用块占比)
```

**识别算法**:
```
1. 扫描标题层级，判断结构化程度
2. 统计代码块、表格、列表占比
3. 分析关键词密度（学习、项目、会议等）
4. 检测特殊元素（公式、图表、任务列表）
5. 综合评分，确定主类型和辅助类型
```

```markdown

2. **链接验证**
```

## 美化规则

### 1. Callout 使用规范

**适用场景**:
- `[!note]` - 概念定义、重要说明
- `[!tip]` - 实用技巧、经验分享
- `[!warning]` - 注意事项、常见错误
- `[!example]` - 示例说明、代码演示
- `[!abstract]` - 核心摘要、总结提炼
- `[!question]` - 思考问题、讨论点

**使用原则**:
- 每个核心概念使用一个 Callout
- 避免过度使用，保持可读性
- Callout 标题简洁明了
- 内容精炼，避免冗长

### 2. 双链使用规范

**适用场景**:
- 相关概念引用
- 知识网络构建
- 扩展阅读链接
- 脚注和补充说明

**使用原则**:
- 保持链接有效性
- 提供链接上下文
- 避免过度链接
- 定期检查链接

### 3. 标签使用规范

**标签结构**:
```yaml
主标签:
  - 学习
  - 项目
  - 读书
  - 工作

子标签:
  - {学科}/{具体领域}
  - {项目名}/{模块}
  - {书名}/{章节}

状态标签:
  - 进行中
  - 已完成
  - 待复习
  - 暂停

优先级标签:
  - 重要
  - 紧急
  - 普通
```

### 4. 表格使用规范

**适用场景**:
- 对比信息
- 数据展示
- 属性列表
- 进度追踪

**格式要求**:
- 使用对齐符号 `:---:`
- 表头简洁明了
- 内容精炼
- 适当添加 emoji 增强可读性

## 注意事项

1. **保持内容优先**: 美化是辅助，内容才是核心
2. **适度美化**: 避免过度装饰，影响阅读
3. **一致性**: 保持整个知识库的风格统一
4. **可维护性**: 美化后的笔记要易于更新
5. **兼容性**: 确保 Obsidian 版本兼容

# Note Starter Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `note-starter` skill that starts new-topic learning-note runs by delegating to `research-planner`.

**Architecture:** `note-starter` is a discoverable facade. It validates its scope, checks a possible existing run, and hands all context to the existing planner; the planner, orchestrator, and workflow retain write operations and phase transitions.

**Tech Stack:** Markdown, YAML, Python 3 skill-validation utilities, platform manifest validation, and the project synchronizer.

## Global Constraints

- Handle new-topic learning notes only; preserve established skills for old-note work.
- Create no command, workflow, state schema, or routing-table entry.
- Never overwrite `workspace/workflow-runs/{run_id}.workflow.md`.
- Declare only `Skill/research-planner` as a dependency and request read-only filesystem access.
- Sync Codex skill changes with the prescribed synchronizer; never edit `.claude/` directly.
